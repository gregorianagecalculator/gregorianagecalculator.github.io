# دليل العمر

موقع تعليمي ثابت باللغة العربية عن حساب العمر والتقويم الميلادي. يشرح الموقع السنوات الكبيسة، والفرق بين السنة الميلادية والهجرية، وطرق الحساب في Excel وGoogle Sheets. وتغطي صفحات الأجيال كل سنة ميلاد من 1900 إلى 2026، مع جدول أعمار كامل داخل كل صفحة.

الموقع المنشور: `https://gregorianagecalculator.github.io/`

## بنية المشروع

```text
arabic-age-site/
├── index.html
├── style.css
├── sitemap.xml
├── README.md
├── .nojekyll
├── blog/
│   ├── leap-year.html
│   ├── hijri-calendar.html
│   └── excel-age.html
└── generations/
    ├── greatest-generation.html
    ├── silent-generation.html
    ├── baby-boomers.html
    ├── generation-x.html
    ├── millennials.html
    ├── generation-z.html
    ├── generation-alpha.html
    └── generation-beta.html
```

- جميع الملفات بترميز UTF-8.
- جميع الصفحات تستخدم `lang="ar"` و`dir="rtl"`.
- لا توجد خطوات بناء، ولا استخدام لـ Jekyll أو أي مولد مواقع ثابت.
- ملف `.nojekyll` موجود حتى يخدم GitHub Pages الملفات كما هي دون معالجة بواسطة Jekyll.
- الخطوط تُحمّل من Google Fonts، مع خطوط نظام احتياطية.
- لا توجد إطارات JavaScript، والحاسبة على الصفحة الرئيسية تعمل بـ JavaScript عادي داخل المتصفح.
- الصفحات الاثنتا عشرة كلها ثابتة، ولا تحتاج إلى قاعدة بيانات أو خادم.
- الروابط الخارجية إلى `agecalculatorsa.com` وإلى دليل حساب العمر في Excel وGoogle Sheets على `https://excel-age-guide.vercel.app` تظهر في الصفحة الرئيسية فقط، ولا تتكرر في صفحات المقالات أو الأجيال.

## صفحات الأجيال

تحل صفحات الأجيال محل صفحات سنة الميلاد المنفردة، وتوفر تغطية متصلة لكل سنة من 1900 إلى 2026:

| الصفحة | نطاق الميلاد | الأعمار في 2026 |
| --- | --- | --- |
| الجيل الأعظم | 1900-1927 | 99 إلى 126 سنة |
| الجيل الصامت | 1928-1945 | 81 إلى 98 سنة |
| جيل طفرة المواليد | 1946-1964 | 62 إلى 80 سنة |
| الجيل إكس | 1965-1980 | 46 إلى 61 سنة |
| جيل الألفية | 1981-1996 | 30 إلى 45 سنة |
| الجيل زد | 1997-2012 | 14 إلى 29 سنة |
| الجيل ألفا | 2013-2024 | سنتان إلى 13 سنة |
| الجيل بيتا | 2025-2026 | أقل من سنة إلى سنة واحدة |

كل صفحة تعرض سنة الميلاد، والعمر بعد يوم الميلاد في 2026، والعمر قبله بسنة واحدة. كما تتضمن شرحاً لسياق الجيل، وأسئلة شائعة، وروابط إلى بقية الأجيال والمقالات.

حدود الأجيال اصطلاحية وتختلف بين المصادر. يبدأ الجيل الأعظم هنا من 1900 لضمان تغطية كل سنة، مع أن بعض المصادر تضع 1900 ضمن الجيل المفقود. ويغطي الجيل بيتا في الموقع سنة 2025 ثم سنة 2026 فقط لأن السنة المرجعية هي 2026، بينما يمتد التصنيف النظري للجيل إلى 2039.

## المعاينة المحلية

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط من داخل مجلد المشروع:

```bash
python -m http.server 8000
```

ثم فتح `http://localhost:8000/` في المتصفح. هذه الخطوة اختيارية للمعاينة فقط.

## النشر على GitHub Pages

### 1. تهيئة مستودع Git محلي

من داخل مجلد `arabic-age-site`:

```bash
cd arabic-age-site
git init
git add .
git commit -m "إطلاق موقع دليل العمر"
git branch -M main
```

### 2. إنشاء مستودع الموقع الشخصي على GitHub

أنشئ مستودعاً عاماً جديداً باسم `gregorianagecalculator.github.io` من حسابك في GitHub. هذا الاسم الخاص يجعل GitHub Pages يخدم الموقع من جذر النطاق، وليس من مسار فرعي. لا تضف إليه ملف README أو ملف ترخيص إذا كان المجلد المحلي يحتوي عليهما بالفعل.

يمكن أن يوجد مستودع واحد فقط بهذا الاسم لكل حساب، ويجب أن تكون ملفات الموقع في جذر الفرع `main` أو داخل مجلد `docs`. إذا كنت قد أنشأت مستودع `arabic-age-site` بالفعل، أعد تسميته إلى `gregorianagecalculator.github.io` من إعدادات المستودع، ثم تأكد من أن ملفات الموقع في الجذر.

اسم المجلد المحلي `arabic-age-site` لا يهم، والمهم هو اسم المستودع على GitHub. ادفع محتويات المجلد إلى جذر المستودع، وليس المجلد نفسه، حتى يبقى `index.html` في الجذر.

### 3. ربط المستودع ودفع الملفات

```bash
git remote add origin https://github.com/gregorianagecalculator/gregorianagecalculator.github.io.git
git push -u origin main
```

إذا كنت تستخدم GitHub CLI، يمكنك إنشاء المستودع ودفع الملفات بالأمر التالي بدلاً من الخطوتين السابقتين:

```bash
gh repo create gregorianagecalculator.github.io --public --source=. --remote=origin --push
```

### 4. تفعيل GitHub Pages

1. افتح صفحة المستودع على GitHub.
2. انتقل إلى `Settings` ثم `Pages`.
3. اختر `Source`: `Deploy from a branch`.
4. اختر `Branch`: `main` والمجلد `/ (root)`.
5. اضغط `Save` وانتظر نشر الموقع.

سيكون رابط الموقع:

```text
https://gregorianagecalculator.github.io/
```

بهذا الشكل يعمل الموقع من الجذر مباشرة. الرابط القديم `/arabic-age-site/` ليس رابط الموقع الحالي، ولا حاجة إلى إعداد إعادة توجيه.

## ملاحظة عن sitemap.xml

ملف `sitemap.xml` يستخدم روابط مطلقة بعد النشر، لأن بروتوكول خرائط المواقع يحتاج إلى ذلك. الصفحة الرئيسية مسجلة بالرابط الجذري، وبقية الصفحات بالروابط الكاملة:

```xml
<loc>https://gregorianagecalculator.github.io/</loc>
```

وتصبح بقية الروابط بالشكل:

```text
https://gregorianagecalculator.github.io/generations/generation-z.html
https://gregorianagecalculator.github.io/blog/leap-year.html
```

## التحقق من Google Search Console

أضف خاصية من نوع `URL prefix` بالرابط الكامل:

```text
https://gregorianagecalculator.github.io/
```

لا تكتب `site:` داخل حقل الخاصية، فهو عامل بحث في Google وليس عنواناً. ولا تضف خاصية `Domain` للرابط `github.io` لأن التحقق منها يحتاج إلى التحكم في DNS، وهو غير متاح لحسابات GitHub Pages.

تمت إضافة وسم التحقق `<meta name="google-site-verification" ...>` داخل `<head>` في `index.html`. بعد أن يصبح الموقع متاحاً، اضغط `Verify` في Google Search Console. لا ينجح التحقق قبل نشر الصفحة وظهور الوسم في الرابط العام.

بعد التحقق، أرسل خريطة الموقع:

```text
https://gregorianagecalculator.github.io/sitemap.xml
```

## تحديث السنة المرجعية

الحسابات في الصفحات مثبتة على سنة 2026. عند الرغبة في تحديث الموقع لسنة لاحقة، يجب تعديل العناوين ووصف الصفحات والجداول في `generations/`، وإضافة السنوات الجديدة إلى نطاق الجيل المناسب، ثم تحديث `sitemap.xml`. لا يكفي تغيير رقم السنة في القالب فقط، لأن الأعمار ونطاقات الأجيال ستتغير معها.
